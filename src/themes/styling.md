# Styling classes

These classes are applied by the launcher UI and can be overridden in a
configured stylesheet.

| Class | Element | Purpose |
| --- | --- | --- |
| `.app-screen` | Outer window | Transparent outer layer-shell window. |
| `.app-window` | Main card | Card containing the search row and results area. |
| `.app-search` | Search entry | Search input and caret styling. |
| `.app-spinner` | File search spinner | Progress indicator while file search is running. |
| `.app-menu` | Triple-dot button | Menu button styling. |
| `.app-list` | Results `ListBox` | The results list widget. |
| `.app-row` | Result row | Individual selectable result row. |
| `.app-icon` | Row icon | Icon displayed beside a result. |
| `.app-title` | Row name | Primary result text. |
| `.app-sub` | Row path | Secondary path or subtitle text. |
| `.app-pill` | Shortcut badge | `Alt + N` shortcut badge. |
| `.app-preview` | Preview panel | Preview panel shown beside results. |

Structural and advanced elements use the `app-advanced-*` prefix:

| Class | Element | Purpose |
| --- | --- | --- |
| `.app-advanced-search-row` | Search row | Container around the entry and menu. |
| `.app-advanced-results-scroll` | Results scroller | Scrollable results card. |
| `.app-advanced-results-area` | Results area | Horizontal results/preview layout. |
| `.app-advanced-content` | Row content | Internal result text container. |
| `.app-advanced-preview-scroll` | Preview scroller | Scrollable preview contents. |
| `.app-advanced-preview-label` | Preview text | Text-based preview output. |
| `.app-advanced-preview-picture` | Preview image | Image preview widget. |
